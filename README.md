# Traney

A clean, responsive personal finance tracker built with React, Vite, and Tailwind CSS.

## Features

- **Multi-Account Tracking**: Manage bank accounts, e-wallets, savings, and cash balances in Indonesian Rupiah (`Rp`).
- **Quick Transactions**: Record expenses, income, and inter-account transfers with live thousand-separator formatting and quick amount shortcuts.
- **Budget & Analytics**: Set monthly spending targets and track category breakdowns in real time.
- **CSV Export & Local Storage**: Automatically persists data in `localStorage` and supports one-click CSV export.
- **Responsive & Themeable**: Optimized for both desktop and mobile viewports with Light and Dark mode support.

## Tech Stack

- **Framework**: React 18 + Vite (JavaScript)
- **Styling**: Tailwind CSS + Google Fonts (`Inter` & `Plus Jakarta Sans`)
- **Icons**: Iconify (`@iconify/react` — Lucide icons)
- **Package Manager**: pnpm

## Getting Started

```bash
# Install dependencies
pnpm install

# Start development server
pnpm dev

# Build for production
pnpm build
```
